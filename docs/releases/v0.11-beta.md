# Flutify 0.11beta

本版针对 [#18](https://github.com/is-hp-is-mad/Flutify/issues/18) 修复桌面搜索框文字选择误触发窗口操作，并将 macOS 安装包纳入发布流水线。应用版本为 `0.0.11+11`。

## 搜索框与窗口手势

- 顶栏拖窗手势移到空白背景，不再包住搜索框和按钮。鼠标拖选、双击选词由输入框处理；搜索框内边距不再启动拖窗或最大化。
- 保留顶栏空白处拖动窗口、双击最大化和还原的行为。
- 新增真实启用窗口手势的回归测试，在 macOS、Windows、Linux 三种 Flutter 平台配置下覆盖拖选、双击选词、搜索框边距和空白标题栏。修复前，搜索框边距拖动和文字双击测试均失败；修复后通过。
- 自动化验证覆盖 Flutter 鼠标事件和原生窗口通道调用；仍需在报告问题的 Mac 上复测录屏中的操作。

## 下载

- macOS 12.0 及以上：`Flutify-v0.11-beta-macos.zip`，解压后将 `Flutify.app` 放入应用程序目录。测试包未做 Developer ID 签名和 Apple 公证，首次打开可能需要在系统设置的“隐私与安全性”中允许打开。
- Windows x64 / ARM64：安装版 `*-setup.exe` 与便携版 `.zip`。
- Android：arm64-v8a、armeabi-v7a、x86_64 和通用 APK，沿用固定 beta 签名。
- 发布现在等待三端构建全部成功，核对九个安装包后生成 `SHA256SUMS.txt`，避免 macOS 构建成功却漏发。

## 已知问题

- 从 v0.09 或更早版本升级时，旧版 Windows 更新器可能仍会失败；请手动运行新版安装包。v0.10 起已修复系统自带 PowerShell 5.1 的更新进程交接。
- Windows 原生 Widevine 许可证 HTTP 403 问题仍未解决，尚未验证原生解密出声；x64 保留实验性原生路径及加载失败回退，ARM64 继续使用 WebView2。
- macOS 仍需不同机型、系统版本与账号的实机验证，构建通过不代表所有播放和系统集成功能均已验证。
