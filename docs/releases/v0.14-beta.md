# Flutify 0.14beta

测试版，应用版本为 `0.0.14+14`。本版把 Android 播放器的联动转场体验带到全平台，歌词支持拖拽排序与原文加翻译，并新增 Linux 桌面支持（实验）。欢迎测试并反馈。

## 播放器：全平台统一场景

- Android 播放器场景（封面、元数据、歌词卡、展开页）抽离为全平台共用：桌面端沉浸歌词并入播放器场景，宽屏布局按横竖屏限制场景宽度。
- 播放器展开路由与 Esc 关闭行为全平台一致；修复从展开页折叠后曲目信息残留的问题。
- 桌面歌词背景与 Android 原生背景对齐，「歌词位置」设置在全屏歌词中生效。

## Android 播放器转场与后台连续播放

- 封面、元数据与歌词卡联动转场：切歌时封面、歌名与歌词卡同步过渡，仿 Apple Music 的队列连续转场；点歌进入队列后播放器卡片自动折叠。
- 详情控件融入歌词卡，歌词焦点与间奏、浏览恢复同步；封面背景改用可复用的原生纹理渲染，降低切歌开销。
- 切歌过程中保留媒体会话，后台连续播放不再中断；恢复队列感知的下一曲预取。
- 修复歌词方向手势与空白区域点击的冲突；手势说明见 [Android 播放器文档](docs/android-media-controls.md)。

## 歌词：来源排序与原文加翻译

- 歌词源优先级支持在设置中拖拽排序。
- QQ 音乐（受限匿名客户端）与网易云歌词提供原文加翻译；QQ 翻译按当前拆行规则对齐，并以覆盖度感知方式回退补全。
- 歌词当前行位置生效；移除歌词模糊选项（观感不变，省 GPU）。
- 修复不完整歌词与拆分来源的翻译缺失。

## Linux 桌面支持（实验）

- 新增 Linux x64 支持（[#25](https://github.com/is-hp-is-mad/Flutify/pull/25)）：全曲播放由后台无窗口的系统 Google Chrome / Chromium（含 Widevine）完成，不再弹出白色 Chrome 窗口；修复进入 Chrome EME 页后不播放、反复「无法连接」重试的问题。详见 [Linux 说明](docs/LINUX.md)。

## Windows 登录与网络

- 登录证书信任补全、PAC/SOCKS 系统代理支持与证书诊断（[#24](https://github.com/is-hp-is-mad/Flutify/pull/24)，[#20](https://github.com/is-hp-is-mad/Flutify/issues/20)）。

## 设置

- 新增「默认循环方式」：应用启动时使用指定循环方式，覆盖上次退出时的状态。
- Connect 设备名默认取本机设备名，不再显示默认的「Web Player」。

## 下载

- Windows x64 / ARM64：安装版 `*-setup.exe` 与便携版 `.zip`。
- Android：arm64-v8a、armeabi-v7a、x86_64 和通用 APK，沿用此前的固定签名，可直接覆盖安装。
- macOS 12.0 及以上：`Flutify-v0.14-beta-macos.zip`，解压后将 `Flutify.app` 放入应用程序目录。未做 Developer ID 签名和 Apple 公证，首次打开可能需要在系统设置的“隐私与安全性”中允许打开。
- Linux x64：实验性 `.deb` 安装包，依赖 `libmpv` 与本机 Chrome / Chromium。
- 共十个安装包，校验和见 `SHA256SUMS.txt`。

## 已知问题

- Windows 原生 Widevine 许可证 HTTP 403 问题仍未解决；x64 保留实验性原生路径及加载失败回退，ARM64 继续使用 WebView2。
- Linux 为实验状态：Canvas 视频封面、分享嵌入、系统媒体控制与任务栏歌词不可用，账号登录与全曲播放需一次性「Web 登录」抓取 sp_dc。
- Android 的 DRM 支持与厂商媒体卡片仍有兼容性差异；vivo 媒体卡片、手机与 PC 间控制权转移仍需实机反馈。
- 从 v0.09 或更早版本升级时，旧版 Windows 更新器可能仍会失败；请手动运行新版安装包。
- 偶尔遇到播放限流（HTTP 429），稍等片刻再试即可。
