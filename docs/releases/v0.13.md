# Flutify 0.13

正式版，应用版本为 `0.0.13+13`。本版主要修复 macOS 窗口拖动问题。

## macOS 窗口拖动修复

- 修复搜索框上半部分会误触发窗口拖动的问题（[#18](https://github.com/is-hp-is-mad/Flutify/issues/18)，[#19](https://github.com/is-hp-is-mad/Flutify/pull/19)）：原生层关闭窗口的隐式拖动（`isMovable = false`），改由 Flutter 顶栏显式提供拖动区。搜索框内拖选、双击选词、清除按钮不再移动或最大化窗口。
- 宽窗口登录页补上专用拖动区，按钮避让交通灯，正文区域不会拖动窗口。
- 顶栏空白处拖动、双击最大化/还原保持正常。

## 下载

- Windows x64 / ARM64：安装版 `*-setup.exe` 与便携版 `.zip`。
- Android：arm64-v8a、armeabi-v7a、x86_64 和通用 APK，沿用此前的固定签名，可直接覆盖安装。
- macOS 12.0 及以上：`Flutify-v0.13-macos.zip`，解压后将 `Flutify.app` 放入应用程序目录。未做 Developer ID 签名和 Apple 公证，首次打开可能需要在系统设置的“隐私与安全性”中允许打开。
- 校验和见 `SHA256SUMS.txt`。

## 已知问题

- macOS 关闭隐式拖窗后，屏幕边缘分屏/平铺、多显示器拔插后的窗口恢复，以及所有页面与覆盖层顶部的拖动尚未完成实机验收，遇到拖不动的区域欢迎反馈。
- 从 v0.09 或更早版本升级时，旧版 Windows 更新器可能仍会失败；请手动运行新版安装包。
- Windows 原生 Widevine 许可证 HTTP 403 问题仍未解决；x64 保留实验性原生路径及加载失败回退，ARM64 继续使用 WebView2。
