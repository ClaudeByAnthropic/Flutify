# Flutify 0.09beta

本版合入 PR #15、#16，修复播放器跳转详情页的导航，完善桌面鼠标光标、侧键和 macOS 历史导航，并补上审查中发现的交互问题。应用版本为 `0.0.9+9`。

## 播放器导航

- 从全屏或沉浸式播放器进入专辑、艺人详情时，先关闭播放器覆盖层，再打开详情页；保留页面历史、播放状态和播放队列。
- 支持普通播放器、沉浸式播放器及两者叠加的场景；桌面端会等待播放器玻璃覆盖层移除，避免详情页被遮挡。

## 桌面鼠标交互

- 首页、资料库、详情页、侧边栏、设置、分享、本地与远程播放器等可点击区域使用手型光标，队列拖动手柄使用抓取光标。
- 歌词区域支持配置光标，同时保留沉浸模式闲置时隐藏光标的行为。
- 鼠标侧键可在当前标签页的历史中后退、前进；macOS 支持 `Cmd+[` / `Cmd+]`，并接入原生滑动事件以支持 Logi Options+ 等鼠标配置。
- 修复对话框或播放器覆盖层打开时，侧键、快捷键和原生导航事件仍会改变底层页面的问题；关闭覆盖层后恢复导航，并保留原有历史。
- 修复没有复制内容或点击动作的分享项仍显示手型光标的问题。

## 验证与构建

- 播放器、导航覆盖层和分享光标的组合回归测试：本地 46 项通过。
- 合并前 CI 的 Flutter 测试：1003 项通过、9 项跳过；Node/Python 检查通过，静态分析无错误或警告。
- Android、macOS、Windows x64 / ARM64 的合并前自测构建全部通过；macOS 鼠标硬件交互尚未实机验证。
- 此 Release 的 Android 包继续使用固定 beta 签名；Android 安装版本码由发布流水线生成。

## 已知问题

Windows 原生 Widevine 的许可证 HTTP 403 问题仍未解决，尚未验证原生解密出声。x64 保留实验性原生路径及加载失败回退，ARM64 继续使用 WebView2。播放、系统媒体集成和升级安装仍需不同设备的实际验证。

## 下载

- Windows x64 / ARM64：安装版 `*-setup.exe` 与便携版 `.zip`。
- Android：arm64-v8a、armeabi-v7a、x86_64 和通用 APK；通常选择 arm64-v8a，不确定时选择 universal。
- 共八个安装包，校验和见 `SHA256SUMS.txt`。macOS 未签名、未公证的自测包仅保留在 Actions Artifacts 中。
