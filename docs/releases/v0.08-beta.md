# Flutify 0.08beta

本版合入 PR #13、#14，新增搜索分页与艺人完整曲库页面，完善播放器长标题滚动和 Android 展开动效。应用版本为 `0.0.8+8`。

## 搜索与艺人曲库

- 搜索结果支持继续加载，各结果分类独立记录分页状态；切换搜索时忽略旧请求的迟到响应。
- 加载下一页失败时保留已有内容，并提供重试入口；过滤无效条目和重复结果时仍按服务端原始分页位置继续请求。
- 艺人详情新增完整专辑与歌曲页面，支持分批加载、空列表和错误提示；自动加载设有边界，避免空页反复请求。
- 补充简体中文、繁体中文、英语和日语文案。

## 播放器体验

- 迷你播放器、桌面播放栏、远程播放栏及歌词页面的长标题支持跑马灯滚动，并适配窗口尺寸和减少动态效果设置。
- Android 全屏播放器从迷你播放器位置展开，加入封面衔接、返回收起和下拉关闭动效。

## 验证与构建

- 两个 PR 组合代码的本地 Flutter 回归：958 项通过、8 项跳过；静态分析无错误或警告。
- PR #14 同步主分支后，质量检查及 Android、macOS、Windows x64 / ARM64 自测构建全部通过；Windows x64 Release 也已在本地编译并启动。
- 新增独立的跨平台自测工作流；Android 自测使用一次性签名。此 Release 继续使用固定 beta 签名，正式包与自测产物分开。

## 已知问题

Windows 原生 Widevine 的许可证 HTTP 403 问题仍未解决，尚未验证原生解密出声；本版不宣称修复该问题。x64 保留实验性原生路径及加载失败回退，ARM64 继续使用 WebView2。播放、系统媒体集成和升级安装仍需不同设备的实际验证。

## 下载

- Windows x64 / ARM64：安装版 `*-setup.exe` 与便携版 `.zip`。
- Android：arm64-v8a、armeabi-v7a、x86_64 和通用 APK；通常选择 arm64-v8a，不确定时选择 universal。
- 共八个安装包，校验和见 `SHA256SUMS.txt`。macOS 未签名、未公证的自测包仅保留在 Actions Artifacts 中。
