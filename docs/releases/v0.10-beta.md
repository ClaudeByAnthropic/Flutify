# Flutify 0.10beta

本版修复 Windows 点击“重启并安装”后更新失败的问题，并包含 PR #17 的顶栏与 macOS 窗口按钮调整。应用版本为 `0.0.10+10`。

## Windows 更新修复

- 更新助手改用隐藏进程启动，兼容系统自带的 Windows PowerShell 5.1，避免脱离进程模式下直接退出、约 10 秒后提示更新失败。无需另装 PowerShell 7；系统路径中的 `v1.0` 不是实际版本号。
- 正确读取含中文的更新计划与安装路径，并修复便携版安装路径含方括号时无法重启的问题；SHA-256 校验直接使用 .NET，避免继承的 PowerShell 模块搜索路径导致校验命令不可用。
- 保留安装前校验、应用退出后安装、便携版备份和取消操作保护；日志记录实际错误、PowerShell 版本及诊断目录。
- 新增 Windows 原生进程回归测试，覆盖安装版交接、便携版替换与重启、重启失败回滚、校验失败和取消操作，并接入 x64 / ARM64 发布构建。

**从旧版本升级：旧版本自身的更新器仍可能出现同一问题。请退出 Flutify，手动运行本页对应架构的 `*-setup.exe`，安装到原目录；便携版请退出后解压到原目录。本版修复将在使用新版后的后续自动更新中生效。**

## 顶栏与 macOS

- 顶栏控件统一为 40px，调整 macOS 交通灯按钮对齐和原生点击区域。
- 保留进入、退出原生全屏后的按钮与标题栏恢复检查。

## 下载与已知问题

- Windows x64 / ARM64：安装版 `*-setup.exe` 与便携版 `.zip`。
- Android：arm64-v8a、armeabi-v7a、x86_64 和通用 APK；继续使用固定 beta 签名，安装版本码由发布流水线生成。
- 共八个安装包，校验和见 `SHA256SUMS.txt`。macOS 未签名、未公证的自测包保留在 Actions Artifacts 中。
- Windows 原生 Widevine 许可证 HTTP 403 问题仍未解决，尚未验证原生解密出声；x64 保留实验性原生路径及加载失败回退，ARM64 继续使用 WebView2。
