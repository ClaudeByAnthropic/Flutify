# Flutify 0.06beta

本版改善歌词翻译、沉浸式播放器和 Android 设置页，并合入 PR #6、#7、#9、#10。

## 歌词与播放器

- 新增「设置 → 歌词 → 当前行位置」，支持 10%–70%；数值越大越靠下，保存后立即应用，默认保留原来的 16%。想让当前行接近中间可先试 40%–50%。
- 翻译按钮与自动翻译可查询网易云已有中文译词，不再受双语预加载开关限制。兼容 `feat.十明` 等曲名署名，改善候选重搜，并淘汰旧的空结果缓存；请求失败可重试。
- 继续使用歌词源提供的译文，中文简繁跟随界面。使用《すずめ》的真实来源数据回放，来源提供的 24 行中文译词全部对齐；来源没有的译文不会自行生成。
- 沉浸式歌词左上角按钮放大，顺序为「退出 → 铺满 → 翻译」；音量移到播放控制下方，更多菜单使用玻璃背景，改善小窗口布局和键盘操作。
- 合入双语歌词与译文时间轴对齐改进，修复 Windows 任务栏双语歌词的编译问题。

## Android 与桌面适配

- 修复 Android 设置页浅色模式下的状态栏图标对比度，补齐设置页和宽屏布局的安全区；设置行改进触摸高度、开关语义和系统文字缩放。
- 合入 Android 系统媒体卡片封面兼容修复（#6）、竖屏网页登录卡片布局修复（#9）和全屏播放器顶部圆角修复（#10）。播放器圆角跟随实际展示形式，窗口缩放后保持正确。
- 合入 macOS 窗口、系统媒体控制、代理及 FairPlay 播放管线（#7）；macOS 包仍为未签名、未公证的自测 Artifact，不上传到本次 Release。
- LRCLIB、网易歌词和 Connect 状态客户端遵守 HTTP 429 / 带 Retry-After 的 503 冷却时间，减少被限流后的重复请求。
- 保留现有自动同意与畅联播放控制行为。

## Windows 原生 Widevine 状态

**Windows 完整播放兼容性尚未完成实机验证，可能不可用。** 编译及产物检查通过不等于实际播放通过。

- 修复原生管线误选 CBCS 文件的问题，明确选择 CENC，并使用 HLS 提供的 Widevine 初始化数据。
- 改善错误分类；真实实验中应用证书获取成功，但许可证仍返回 HTTP 403，**尚未验证原生解密出声成功**。
- Windows x64 继续开启原生实验，加载失败回退 WebView2；ARM64 保留 WebView2。没有随包分发 Widevine CDM。
- 本批功能的本地 Windows x64 Release 编译通过，21 个随包原生文件的架构及 VC 运行库依赖检查通过。详见 [实验记录](https://github.com/is-hp-is-mad/Flutify/blob/v0.06-beta/docs/WIDEVINE.md)。

发布前回归：Flutter 测试 762 项通过、8 项跳过；发布流程、EME 播放与自动同意脚本测试 25 项通过；Dart 静态分析无错误或警告，仍有 info 提示。

Windows x64 / ARM64 提供安装版和便携版；Android 提供 arm64-v8a、armeabi-v7a、x86_64 和通用 APK。发布流程在 Android 与 Windows 构建及产物校验通过后上传，校验和见 `SHA256SUMS.txt`。
