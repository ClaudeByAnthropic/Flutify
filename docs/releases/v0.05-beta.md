# Flutify 0.05beta

**Windows 可能不可用（未验证）。** 构建成功仅代表编译及产物检查通过，Windows 本版尚未完成真实账号播放和设备兼容性验证。

## 更新

- 本机 Connect 接收端在加载、播放和展示前跳过广告，并过滤待播列表；服务端是否接受跳转仍待真实账号验证。
- 歌词使用 Spotify / LRCLIB 提供的译文，中文类型跟随界面；改善译词匹配、重试和切歌状态，翻译按钮移至展开 / 全屏按钮左侧。
- 保留英语和简体中文，新增繁体中文与日语；语言选项支持换行，任务栏歌词设置示例适配深色模式。
- 首页支持下拉和按钮刷新，改善刷新并发与语言切换后的内容缓存。
- 加入 Spotify Canvas、外部播客播放及缓存改进，修正 UTF-8 解码和 Connect 收听状态；桌面 DRM 延迟初始化。
- Windows x64 开启实验性原生 Widevine：每次会话获取应用证书，重新发现浏览器更新的 CDM，原生加载失败后回退 WebView2。Android 继续使用系统 Media3 / Widevine；Windows ARM64 继续使用 WebView2。

## Windows 验证范围

- 发布前本地 x64 Release 编译通过；自动化测试 573 项通过、6 项显式跳过。
- Chrome / Edge CDM 初始化、无许可证解密返回 `kNoKey`、容器重写及子进程退出检查通过。
- 真实原生实验中应用证书返回 HTTP 200，许可证返回 HTTP 403，**尚未验证原生播放成功**。证书刷新不等于许可证一定获准。
- 保留 WebView2 依赖；没有随包分发 Widevine CDM。详见 [实验记录](https://github.com/is-hp-is-mad/Flutify/blob/v0.05-beta/docs/WIDEVINE.md)。

Windows x64 / ARM64 提供安装版和便携版；Android 提供三种 ABI 和通用 APK。全部平台构建及产物校验通过后发布，校验和见 `SHA256SUMS.txt`。
