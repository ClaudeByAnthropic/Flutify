# Flutify 0.07beta

本版新增应用更新功能，改善语言设置、歌词交互与性能，并修正登录失效清理及请求缓存。应用版本为 `0.0.7+7`，包含 PR #11、#12。

## 更新检查与安装

- 启动后自动检查 GitHub 版本及更新内容；后台检查间隔至少 6 小时，设置页可立即检查。
- 支持「手动更新」「自动更新」「跳过本次更新」「不检查更新」。默认手动更新；自动模式下载完成后提示，由用户确认重启安装，避免打断播放。
- 根据平台和架构选择更新包，支持四路并发分段下载；服务器不支持 Range 时回退单路。校验文件长度和 SHA-256，不安装未完成或校验失败的文件。
- Windows 便携版退出后覆盖更新，安装版打开安装程序；Android 下载对应 APK 后调用系统安装界面，必要时引导开启安装权限。安装前再次校验，Windows 退出沿用播放状态保存流程。
- 保留下载完成的待安装状态；macOS 等未接入自动安装的平台提供发布页入口。更新安装仍待实机端到端验证。

## 界面与歌词

- 界面语言改为 Material 3 Expressive 风格下拉菜单；翻译按钮改为圆形图标按钮，保留状态提示。
- 合入 PR #12 的 Android 双语歌词切换、重排稳定性及翻译按钮位置改进。
- 歌词玻璃控件共享背景采样，改善模糊闪烁；流动封面降低刷新频率，暂停后继续保持旋转位置，减少重复模糊计算。
- 修复歌词背景首次处于暂停状态、未播放便关闭页面时的动画生命周期异常。
- 桌面沉浸式播放器把音量条纳入玻璃控制台，改善窄窗口布局；全屏切换及退出歌词页前等待模糊图层移除，降低窗口变化时的合成器崩溃风险。
- 播客列表小封面按显示尺寸解码，减少大图内存占用。

## 登录、请求与播放稳定性

- 当前账号请求明确返回 401 时，清除应用保存的登录凭据及应用 WebView 全部 Cookie，退出登录并停止相关播放和 Connect。403 不据此清除登录态。
- 合并并发清理，忽略旧会话的迟到响应；Cookie 清理失败保留重试标记，启动及重新登录前重试，避免恢复残留会话。
- 区分 Web token、许可证与媒体错误，避免把无关的 401 / 403 文本误判为需要重新登录。
- Connect client-token 按服务端有效期提前刷新，并合并并发申请；失效后丢弃旧请求结果，播放端跟随当前区域主机。
- 统一桌面 AP 握手、登录和 HTTP 客户端的版本及平台配置，移除 AP 可选字段中的应用标识；默认 Connect 设备名改为「Web Player」，保留用户自定义名称。生产 TLS 指纹尚未对齐。
- Windows 原生解码器停止失败时释放并停用该解码器，避免清理错误阻塞后续 WebView 回退；尚未打开解码器的许可证失败不再触发多余停止操作。

## macOS 构建

- 合入 PR #11，最低系统版本提高到 **macOS 12**，适配较新 Xcode；macOS CI 固定 Flutter 3.44.9。
- macOS 包继续作为未签名、未公证的自测 Artifact；本地没有 macOS 设备，未验证播放与系统集成。

## Windows 原生 Widevine 状态

**许可证 HTTP 403 尚未解决，尚未验证原生解密出声。** x64 保留实验性原生路径及加载失败回退，ARM64 继续使用 WebView2；不随包分发 Widevine CDM。

- 新增独立宿主验证及请求元数据诊断；提交真实自身 EXE 和 CDM 后可生成加密身份，但不代表宿主认证通过，诊断接入未加入生产宿主。
- 同令牌、同证书、同 Dart 网络客户端对照仍为 Chrome 200 / 许可证可用、独立宿主 403 / 空正文；预加载系统 DXVA 与等待初始化未解决问题。
- 自身有效宿主签名与完整接入资料仍缺失，服务端具体拒绝原因未知。详见 [Widevine 实验记录](https://github.com/is-hp-is-mad/Flutify/blob/v0.07-beta/docs/WIDEVINE.md)。
